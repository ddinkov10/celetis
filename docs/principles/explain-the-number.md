# Explain the number

## Applies when

A task reports or uses a measured performance or quality result.

## Rule

Define what the measurement includes and excludes. Report the sample size, the spread of the
results, and the factors that limit the conclusion. Check that the measured work ran and that
cached results, skipped work, or a different workload did not produce a misleading result.

Treat an insufficient sample as a limitation. Match the strength of the claim to the evidence.

## Check

Report the measurement scope, sample size, spread, limiting factors, and evidence against
misleading results. Mark an insufficient sample as a limitation.
