# Model the domain

## Applies when

State combinations, growing branches, or repeated shape rules make a domain unclear.

## Rule

Identify the valid states, their relationships, and the rules repeated across branches or data
shapes. Choose a model that removes invalid states or gives each repeated rule one home. Keep
clear local logic when a new model would add structure without removing a concrete problem.

## Check

Show the invalid states or duplicated rules that the chosen model removes. If local logic is
sufficient, state why it remains clear and covers the required states.
