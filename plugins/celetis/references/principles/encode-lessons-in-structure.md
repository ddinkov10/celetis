# Encode lessons in structure

## Applies when

A mistake repeats, or the same corrective instruction is needed again.

## Rule

Record the mistake and the condition that lets it recur. Use a permitted type, interface,
validation rule, lint rule, or verification gate to reject that mistake. Keep a rule as text
when its correct use requires judgment that the structure cannot express.

Use a check that the project permits. This rule does not authorize a tracked test where the
project prohibits one.

## Check

Show that the structural constraint rejects the recorded mistake. If the rule remains text,
record why its use requires judgment.
